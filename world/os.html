RaBbLE-OS

⚠ Developer Preview · enter at your own risk
◈ what it is

RaBbLE-OS is a sovereign substrate: a Fedora 43 / Hyprland daily driver built for tiling-WM-literate users who want to run the full RaBbLE loop locally, offline-capable.

The cloud is an extension. The OS is where RaBbLE is sovereign. The machine goes dark; the loop keeps running.

  • Fedora 43 base, rolling, minimal footprint
  • Hyprland (Wayland): tiling compositor, keyboard-driven
  • x86_64: generic VM-verified. ProArt P16 is documented but not the target bar.
  • Local-first: all core members run offline. Cloud is deliberate, not default.
◈ what Developer Preview means

This is not a polished release. It is a working substrate that installs and runs, daily-survivable for a Linux and tiling-WM-literate user. Rough edges are documented below. Do not install this on hardware you cannot afford to reinstall.

◈ install path

RaBbLE-OS ships as a netinstall ISO + Kickstart. The bootstrap spell clones the full Collective on first boot.

1 · bootstrap the Collective (clones all members)
curl -fsSL https://joinrabble.world/setup.sh | bash
2 · Fedora netinstall: download the minimal ISO
https://fedoraproject.org/en/server/download/
# Select: Netinstall, x86_64
3 · point the installer at the Kickstart
# Boot the ISO, press Tab / e on the GRUB entry, append:
inst.ks=https://raw.githubusercontent.com/RaBbLE-Collective/RaBbLE-OS/new-horizons/ks/rabble-os.ks

The Kickstart runs %post, clones the Collective, and calls Bootstrap.sh. Ansible then applies the full package manifest and dotfiles. First full run takes 15–30 min depending on your connection.

◈ recovery path

If the system fails to boot to Hyprland, F2 at GRUB drops to a recovery shell. The mechanism is SYSTEMD_SULOGIN_FORCE: no root password required, just press Enter. From there you can inspect logs, reinstall packages, or rerun Bootstrap.sh.

◈ known rough edges · deferred to Episode 2 (Exodus)
  • Dolphin / Kate theming: KDE apps partially themed; some icon labels dim on first login (requires logout/login)
  • NVIDIA track: untested; generic x86_64 target is AMD/Intel only
  • asusctl / XDNA2 hardware polish: ProArt P16-specific, not the generic bar
  • Full reproducible bake: Kickstart + Ansible is the current path; container image is Exodus
  • Mobile / ScRibLE: handheld surface is Epoch 0, Echo 1 target
  • aarch64 / Pi: Ansible role scaffolded; not tested end-to-end
◈ what comes next

RaBbLE-OS leaves Developer Preview in Episode 2 (Exodus), when the Pair forms and the Personal Cosmos architecture is in place. The OS becomes the local-first surface for persistent memory and ambient behavioral learning.

For now: it runs. The loop is local. That's the honest beginning.
